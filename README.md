# SplitBill

Lisää, muokkaa, poista ja järjestä yhteisiä kuluja. Yhteenveto näyttää yhteissumman ja osuuden henkilöä kohden.

Tekniikat: HTML, CSS, JavaScript, JSON Server, REST API, Git ja GitHub.

## Tiedostot

| Tiedosto | Tehtävä |
| --- | --- |
| `index.html` | Sivun rakenne, näkymät ja lomakkeet. |
| `style.css` | Ulkoasu, väriteemat ja eri näyttöleveydet. |
| `script.js` | Hakee, lisää, muokkaa ja poistaa kuluja sekä päivittää näkymät. |
| `db.json` | Sisältää tallennetut kulut. |
| `package.json` | Määrittää riippuvuudet ja palvelimen käynnistyskomennon. |
| `package-lock.json` | Lukitsee pakettien tarkat versiot samaa asennusta varten. |
| `.gitignore` | Kertoo Gitille, mitkä tiedostot jätetään pois. |
| `README.md` | Kertoo, mitä sovellus ja sen tiedostot tekevät. |
